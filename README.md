# Свадебное приглашение · Виктория & Константин

Одностраничный сайт-приглашение (07.07.2027, Грузия · Chateau Mephis Kalaki), опубликован через GitHub Pages.

## Личные ссылки для гостей

- `?guest=Татьяна` — «Дорогая Татьяна!»
- `?guest=Сергей&form=male` — «Дорогой Сергей!»
- `?guests=Ольга и Сергей` — «Дорогие Ольга и Сергей!»

## Где что менять

Всё в `index.html`, блок `VARS` в начале скрипта: имена, дата, место, город и `rsvpUrl` (ссылка на Google-анкету).
Ссылка на Instagram — элемент `id="instaLink"`.
